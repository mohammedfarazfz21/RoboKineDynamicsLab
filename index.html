🚀 Supabase Setup Guide

Following these steps will enable User Login and Cloud Saving.
  1. Go to supabase.com and create a free project.
  2. In your project dashboard, go to Settings (gear icon) > API.
  3. Copy the Project URL and the anon public key.
  4. Open scripts/auth.js in your code editor.
  5. Replace the placeholders at lines 12 and 13 with your copied values.
  6. Refresh this page. You can now Sign Up and Login!
